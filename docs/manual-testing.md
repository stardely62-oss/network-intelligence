# Ручная проверка на Windows 11 (до первого релиза)

Релиз 0.1 создаётся только после прохождения этого списка на реальной
Windows 11 x64. Установщик берётся из артефакта CI
(`network-intelligence-windows-x64-<sha>`), SHA-256 сверяется с `SHA256SUMS.txt`.

## Установка и запуск
- [ ] Установщик запускается без прав администратора (режим «для текущего пользователя»).
- [ ] Приложение открывается, в боковой панели — «без прав администратора».
- [ ] `%LOCALAPPDATA%\io.github.stardely62.networkintelligence\ni.sqlite3` создан.

## Обзор
- [ ] Список процессов заполнен, иконки отображаются.
- [ ] Discord / браузер показан одной строкой «×N»; в режиме «Процессы» — отдельные PID.
- [ ] Системные процессы (`svchost.exe`, `System`) помечены «ограничено правами» / «системный».
- [ ] Число TCP/UDP совпадает с `Get-NetTCPConnection -OwningProcess <PID>` / `Get-NetUDPEndpoint` (с поправкой на время снимка).

## Сессия
- [ ] Запуск записи для браузера; открыть несколько сайтов — в «Соединениях» появляются адреса, включая успешные (ESTABLISHED).
- [ ] IPv6-адреса отображаются отдельно (если провайдер даёт IPv6).
- [ ] UDP-строки показаны без удалённого адреса.
- [ ] Маркер и заметка появляются в «Хронологии» и в сессии.
- [ ] Закрыть вкладку — endpoint получает «исчез», в хронологии — «нет в снимке, последний раз …».
- [ ] Закрыть и снова открыть приложение во время записи (с «Все процессы этого файла») — новый процесс подхватывается, старый помечен завершённым.
- [ ] Принудительно завершить Network Intelligence во время записи; после запуска сессия «прервана», данные на месте.

## Проверки
- [ ] DNS `discord.com`; TCP `discord.com:443` (IPv4 и IPv6 раздельно); TCP к закрытому порту = «отказ»; TCP `192.0.2.1:443` = тайм-аут/недоступен.
- [ ] UDP STUN к `stun.l.google.com:19302` — ответ; UDP к `192.0.2.1:9` — «ответа нет» с пометкой «не означает блокировку».
- [ ] «Проанализировать» — выводы с наблюдениями, гипотезами, альтернативами и ограничениями.

## Отчёты и настройки
- [ ] Экспорт JSON по умолчанию не содержит частных IP, имени пользователя, путей и заметок.
- [ ] «Удалить всю историю» очищает список; размер базы уменьшается.
- [ ] Интерфейс не зависает при записи 10+ минут браузера с большим числом вкладок.
