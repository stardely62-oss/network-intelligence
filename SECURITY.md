# Политика безопасности

## Сообщить об уязвимости

Не создавайте публичный issue. Используйте приватный отчёт GitHub
(**Security → Report a vulnerability**) в этом репозитории.

## Модель угроз (кратко)

| Угроза | Защита |
|---|---|
| Повышение привилегий через приложение | UI и весь сбор работают без прав администратора; привилегированной службы в 0.1 нет |
| Выполнение команд из интерфейса | фиксированный набор команд Tauri; нет shell-плагина, нет fs-плагина, нет команды «выполнить» |
| Запись в произвольные файлы | единственная запись вне каталога данных — экспорт в файл, выбранный в системном диалоге сохранения; только `.json` |
| Сканирование сети / атака через проверки | проверки только по действию пользователя, одна цель (имя или один IP), диапазоны и CIDR отклоняются, ≤ 8 адресов на семейство, тайм-аут ≤ 30 с, UDP-полезная нагрузка ≤ 512 байт |
| Утечка чувствительных данных при экспорте | по умолчанию частные/локальные IP → псевдонимы, пути → имя файла, заметки и маркеры удаляются; редактирование применяется ко всему JSON-документу, а не к отдельным полям |
| Доступ других пользователей к истории | база в `%LOCALAPPDATA%` текущего пользователя (наследуемый ACL: пользователь, SYSTEM, администраторы); на Unix-системах — права `0600` |
| Восстановление удалённой истории | «Удалить всю историю» выполняет `DELETE` + `wal_checkpoint(TRUNCATE)` + `VACUUM` |
| Внедрение скриптов в WebView | строгий CSP (`script-src 'self'`), `freezePrototype`, данные выводятся через React без `dangerouslySetInnerHTML` |
| Подменённые зависимости | lock-файлы в репозитории, `cargo audit` и `pnpm audit` в CI, actions закреплены по SHA |

## Что Network Intelligence не делает

Не устанавливает драйверы, не перехватывает и не изменяет пакеты, не меняет
брандмауэр, DNS, hosts и настройки Windows, не отключает средства защиты, не
читает содержимое трафика, пароли, токены и cookie, ничего не отправляет
разработчикам.

минимальным (запуск/остановка сбора для заданных PID, чтение агрегированных
событий), канал — именованный канал с DACL и проверкой клиента. Проект — в
[docs/roadmap.md](docs/roadmap.md) и [docs/bridge-integration.md](docs/bridge-integration.md).
